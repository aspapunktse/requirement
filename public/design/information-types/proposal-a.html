Information Types · Proposal A

Register and drawer

Information Types sit in the main navigation, beside Systems, because everyone reads them. The catalogue is a register table with a drawer for editing; "Where can I put this information?" is a pick list with three result groups; the owner ticks types in a list and then chooses a level that can't go below them. Use the tabs for each surface, the acting-user menu in the header to see the catalogue read-only or editable, and the Mode switch for dark.
