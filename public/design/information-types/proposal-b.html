Ladder

Everything is arranged by Sensitivity Level. The catalogue is five lanes of cards; "Where can I put this information?" shows the scale with a cut line at the type's level; the owner's picker is a ladder where each type sits on its rung, rungs below the floor are locked, and adding a type above the level asks before it raises the level. The Systems list filters from a sidebar grouped by level. Information Types sit in the main navigation beside Systems. Switch the acting user in the header to see the catalogue read-only or editable.
