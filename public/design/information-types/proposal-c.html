Information Types · Proposal C

Matrix and tags

Information Types behave like tags. The catalogue edits in the row and explains a refused delete in a dialog; "Where can I put this information?" is a matrix of Systems against types; the owner types into a tag field instead of ticking a long list, and the level rises on its own with an Undo; a checklist on the System page shows what submit needs. On the Systems list, a type tag in a row is a filter. Information Types sit in the main navigation beside Systems. Switch the acting user in the header to see the catalogue read-only or editable.
