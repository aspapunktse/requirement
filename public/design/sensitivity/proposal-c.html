Sensitivity Levels · Proposal C

Tag with icon

A level is a tag with a coloured left edge and its own icon: globe, building, padlock, double padlock, shield. The icon is a second cue next to the label, so the level is clear even in a screenshot printed in grey. Owners choose from cards that name example information; Admins edit a form with a live preview of the list row, the System header and the Control drawer beside it.
